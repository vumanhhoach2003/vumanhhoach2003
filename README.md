## 🏛️ VN30 Data Lakehouse

🔗 **Repository:**  
[github.com/vumanhhoach2003/vn30-lakehouse](https://github.com/vumanhhoach2003/vn30-lakehouse)

> Xây dựng hệ thống Data Lakehouse phục vụ thu thập, xử lý và tổ chức dữ liệu thị trường chứng khoán VN30.

Dự án được xây dựng với mục tiêu kết hợp nền tảng **Công nghệ Tài chính** với định hướng phát triển trong lĩnh vực **Data Engineering**.

### 🏗️ Kiến trúc

```text
                  Data Source
                      │
                      ▼
                Apache Airflow
                      │
                      ▼
                Bronze Layer
                  Raw Data
                      │
                      ▼
                Apache Spark
                      │
                      ▼
                Silver Layer
                Cleaned Data
                      │
                      ▼
                Apache Spark
                      │
                      ▼
                 Gold Layer
              Analytics-ready
                      │
                      ▼
             Analytics / BI / ML
```

### ⚙️ Công nghệ sử dụng

- **Apache Airflow 2.10** – Điều phối và tự động hóa Data Pipeline.
- **Apache Spark 3.5 / PySpark** – Xử lý và biến đổi dữ liệu.
- **MinIO** – Object Storage tương thích S3.
- **Delta Lake** – Quản lý dữ liệu theo kiến trúc Lakehouse.
- **Hive Metastore** – Quản lý metadata của bảng dữ liệu.
- **Docker & Docker Compose** – Container hóa và triển khai môi trường.
- **Python & SQL** – Xử lý và truy vấn dữ liệu.

### 🥉 Bronze Layer

Lưu trữ dữ liệu thô từ nguồn ban đầu.

Mục tiêu:

- Giữ lại dữ liệu gốc.
- Hỗ trợ kiểm tra và tái xử lý dữ liệu khi cần.
- Tách biệt dữ liệu raw khỏi các bước xử lý phía sau.

### 🥈 Silver Layer

Thực hiện quá trình:

- Làm sạch dữ liệu.
- Chuẩn hóa dữ liệu.
- Xử lý dữ liệu thiếu.
- Xử lý dữ liệu trùng lặp.
- Chuẩn hóa kiểu dữ liệu.
- Chuẩn bị dữ liệu phục vụ phân tích.

### 🥇 Gold Layer

Tổ chức dữ liệu đã được xử lý để phục vụ:

- Phân tích dữ liệu.
- Xây dựng dashboard.
- Tính toán các chỉ số.
- Các bài toán Machine Learning trong tương lai.

### 💡 Những gì mình học được

Thông qua dự án này, mình có cơ hội thực hành:

- Thiết kế một Data Pipeline end-to-end.
- Tổ chức dữ liệu theo **Medallion Architecture**.
- Làm việc với **Apache Spark và PySpark**.
- Điều phối workflow bằng **Apache Airflow**.
- Sử dụng Object Storage theo chuẩn S3.
- Làm việc với kiến trúc **Data Lakehouse**.
- Tích hợp nhiều thành phần dữ liệu trong cùng một hệ thống.
- Sử dụng Docker để xây dựng môi trường có khả năng tái tạo.
- Debug các vấn đề xảy ra giữa nhiều service.
- Kết hợp kiến thức tài chính với xử lý và phân tích dữ liệu.
