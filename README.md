## 📌 Dự án tiêu biểu

### 🏛️ [VN30 Lakehouse](https://github.com/vumanhhoach2003/vn30-lakehouse)

> **Dự án Data Lakehouse thu thập, xử lý và phân tích dữ liệu thị trường chứng khoán VN30.**

Dự án được xây dựng nhằm kết hợp nền tảng **Công nghệ Tài chính** với định hướng phát triển trong lĩnh vực **Data Engineering**.

### Kiến trúc & Công nghệ sử dụng

- 🥉🥈🥇 Xây dựng **Medallion Architecture gồm Bronze – Silver – Gold** để tổ chức và xử lý dữ liệu theo từng lớp.
- ⚙️ Xây dựng và điều phối pipeline dữ liệu tự động bằng **Apache Airflow 2.10**.
- ⚡ Sử dụng **Apache Spark 3.5 / PySpark** để xử lý dữ liệu.
- 🗄️ Sử dụng **MinIO** làm hệ thống lưu trữ Object Storage tương thích S3.
- 🔄 Tích hợp **Delta Lake** nhằm hỗ trợ ACID Transaction, quản lý schema và versioning dữ liệu.
- 🐝 Tích hợp **Hive Metastore** để quản lý metadata của các bảng dữ liệu.
- 🐳 Container hóa toàn bộ hệ thống bằng **Docker Compose**, giúp môi trường triển khai có tính nhất quán và dễ tái tạo.
