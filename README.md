#### 🏛️ [vn30-lakehouse](https://github.com/vumanhhoach2003/vn30-lakehouse)
> **Kiến trúc Data Lakehouse thu thập và phân tích dữ liệu rổ chỉ số chứng khoán VN30.**
* Triển khai kiến trúc **Medallion Architecture (Bronze - Silver - Gold)** đảm bảo tính toàn vẹn và chất lượng dữ liệu.
* Điều phối tự động hóa end-to-end pipelines qua **Apache Airflow 2.10**.

* Toàn bộ hệ thống được container hóa và triển khai đồng bộ qua **Docker Compose**.
